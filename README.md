# Mzansi Market - Stock Manager & Ordering System

A full-stack web application designed for stock management and local trade ordering.

## Features
- **Branded Authentication**: Custom logo (`🛒`) and slogan (*"Empowering local trade, simplified stock."*).
- **Role-Based Access**: Distinguishes between **Customer** (placing orders) and **Store Manager** (inventory management, stock alerts).
- **Modern Theme**: South African amber/gold palette with dark-mode slate components.
- **RESTful API Backend**: Express, Node.js, and MongoDB persistence with JWT authentication.

## How to Run Locally
1. Extract the `.zip` archive.
2. Open terminal in the project directory and run `npm install`.
3. Start local MongoDB database instance.
4. Run `npm start`.
5. Open `http://localhost:5000/login.html` in your web browser.
